# A4 结果：等码率下的覆盖损失（剪枝 vs 量化 vs 逐基元比特）

**状态**：已执行完毕（2026-11-13）。预注册见 `experiments/METHOD_PLAN.md` §A4（A4.0–A4.6）。
**判定（预注册口径，未事后改动任何码率点 / 场景 / 常数）**：

| 判据 | 结论 | 数字 |
|---|---|---|
| **C1** 等字节下非剪枝族比剪枝族覆盖损失小 ≥3.0 pp | **成立** | 2.0× **+6.36 pp**、2.5× **+8.94 pp**、3.0× **+11.35 pp**，三点均 4/4 场景同向、区间不含 0 |
| **C2** 尾部图权重（`at`）比可见度权重（`am`）在分配器里改善 ≥1.0 pp | **不成立（且是"空"不是"假"）** | 5 个码率点全部 \|mean\| ≤ 0.07 pp，2.0–3.0× 上 ≤ 0.003 pp |

按 A4.4 的三结局表，A4 落在**第二行**：只主张「**等码率下比特优于计数**」，不主张证书泛函在分配器里有用。

## 1. 做了什么

四个 checkpoints（bicycle / flowers / stump / treehill，归档 40k 迭代点），32 个变体，全部在**同一批 held-out 视角**上重渲后按 `audit_bound.py` 的规范协议算覆盖率：

- 每场景 25 / 22 / 16 / 18 个 test 视角，`cal_frac=0.5` → 标定 12 / 11 / 8 / 9，评估 13 / 11 / 8 / 9；
- 每个 split 用 **clean 的标定残差**算 `q = C.cq(·, 0.1)`（`ceil((n+1)·0.9)` 序统计量），
  `drop = mean(edit ≤ q on 评估) − mean(clean ≤ q on 评估)`，负 = 变差；
- 400 splits（`split_perms`，seed 0），逐 split 配对求差，报告 2.5/97.5 分位；
- clean 覆盖率 89.8 / 90.1 / 89.9 / 90.2 %（分位数定义下应 ≈ 90%，自检通过）。

字节模型（literal，不假设熵编码）：`bytes/prim = 44 + 3K·b/8`，`K=(degree+1)²=16`，fp32 = 236 B/prim。
四个族：`q*` 全保留 + 均匀 SH 量化；`p*` Fisher 对角 top-k 剪枝（fp32 SH）；`p*_q*` 两者叠加；
`am*/at*` 全保留 + 逐基元比特（拉格朗日率分配，权重分别为可见度 / 尾部图）。

## 3. C1：等字节下"比特"全面压过"计数"

判据（预注册）：非剪枝族（`q* / p*_q* / am* / at*`）在同一字节预算上的覆盖率损失，比剪枝族（`p*`）**小**
≥3.0 pp，逐 split 配对区间不含 0，且 ≥3/4 场景同向；至少 3 个码率点满足。

| 码率 | C1 均值 (pp) | 最差场景 (pp) | 同向 | 通过 |
|---|---|---|---|---|
| 2.0× | **+6.36** | +2.84 | 4/4 | ✅ |
| 2.5× | **+8.94** | +4.21 | 4/4 | ✅ |
| 3.0× | **+11.35** | +5.67 | 4/4 | ✅ |
| 3.5× | — | — | — | 未覆盖（prune 族上限 3.33×） |
| 4.0× | — | — | — | 未覆盖 |

3.5× / 4.0× 不是"没通过"，是**没有对照**：prune 族最狠的一档 `p30` 只到 3.33×，按预注册约定**不外推**。

最锋利的两个数：**3.33× 的剪枝（Fisher，N12 里 8/8 最优的准则）在 bicycle 掉 12.71 pp、flowers 掉 19.18 pp；
3.47× 的 4-bit SH 量化（压缩比更高）掉 0.02–0.05 pp，PSNR 只掉 0.02–0.05 dB。**

## 4. C2：尾部图权重在分配器里没有可测优势——但这是"空"不是"假"

| 码率 | C2 均值 (pp) | 最差场景 (pp) | 通过 |
|---|---|---|---|
| 2.0× | −0.0002 | −0.0029 | ❌ |
| 2.5× | −0.0002 | −0.0029 | ❌ |
| 3.0× | +0.0000 | −0.0018 | ❌ |
| 3.5× | −0.0022 | −0.0107 | ❌ |
| 4.0× | −0.0673 | −0.2323 | ❌ |

`am` 与 `at` 的差别在 1e−3 pp 量级；只有在 4.0×（均值 2.49 bit）才有 0.07 pp 的差别，方向还是**尾权略差**。

**必须说清楚的是为什么**：在这个动作空间里根本没有可分配的失真。
全保留 + 均匀量化的 `q8`（2.57×）覆盖率损失是 0.00 pp、`q6`（2.95×）仍是 0.00 pp、`q4`（3.47×）是 0.02–0.05 pp。
既然**任何**符合预算的比特分配都已经贴着零损失，权重怎么选都不会有区别——C2 的分辨力上限是 0，
所以它否证的不是"尾权没用"，而是"这个问题在本区间是退化的"。这是一条关于预注册本身的教训：
**判据的有效性取决于效应量是否有正的头部空间**；我在 A4.4 里没有先验证这一点。

## 5. 三个结构性事实（可直接进论文）

1. **全保留 + 量化的压缩比上限是 4.21×**。字节模型 `44 + 3K·b/8` 里 44 B 是几何/不透明度（32 bit 浮点 ×4 类），
   量化 SH 最多把另外 192 B 压到 12 B（b=2）。**4.21× 以上必须动基元数**，没有第三条路。
2. **叠加量化在给定保留率下完全免费**（`joint` vs 同保留率 `prune`）：
   `p90_q6` vs `p90`、`p80_q6` vs `p80`、`p70_q6` vs `p70`、`p60_q8` vs `p60`、`p50_q8` vs `p50`
   的最大偏差 **0.00 pp**（`_q4` 组 0.02–0.04 pp）。也就是说 `p50_q8` 的 5.13× 里，
   5.13/2.00 = 2.57× 那一半来自量化、而数一半（`p50`）独占了全部 4.98–11.64 pp 的损失。
3. **量化只有到 3 bit 以下才开始付钱**（`q3` 3.81×：0.12–0.40 pp；`am4.0` 2.49 bit 均值：0.04–0.25 pp）。
   这是一条剂量—反应曲线，且与 PSNR 同向（`q3` −0.09…−0.32 dB，`q4` −0.01…−0.05 dB），
   说明覆盖率指标并不是"对量化免疫"，而是**量化在这批 checkpoints 的 SH 里确实几乎不携带失真**。

## 7. 注意事项（不要被误读）

- **treehill 的 clean PSNR 只有 9.41 dB**：归档 GT 与渲染之间存在逐视角曝光失配
  （`a4_exposure_check.py`：所需增益中位 0.90、最小 0.56；灰度 PSNR 15.87 dB，仿射对齐后 20.98 dB）。
  该场景在所有族里响应都最小（`p30` −6.64 vs flowers −19.18），与 N12 里它本来就是一列弱信号一致。
  覆盖率是自校准的（`q` 来自同一对渲染/GT），所以 drop 仍可比；但**不要引用 treehill 的 PSNR**。
- 8-bit 是这族量化的精确 no-op（`q16/q12/q10/q8` 四档的 PSNR 与 clean 的差都在 ±0.0004 dB 内，覆盖率差 0.00 pp），
  所以 `q8` 同时是噪声地板基准；`q6` 也只差 0.003 dB。真正开始付钱是 `q3`（−0.21…−0.34 dB）。
- 分配器的 `D_i(b)` 是**精确量化失真 + 权重**的代理，不是重渲测 ΔP。C1 只用到 `q*/am*/at*` 的端到端重渲结果，
  代理只影响"每个基元分几 bit"，而这个自由度在本区间内不产生差异（见 §4）。
- A4 全部结论只覆盖 `q=C.cq(·,0.1)`、`blur=15`、`factor=4`、`--gt-convention archive`；
  换 `alpha` 或换模糊尺度都是新的预注册，不能事后拿来救 C2。

## 9. 对论文的处置建议

1. **改协议**：任何"同等预算"的比较必须按字节（或按实测文件大小）对齐，不能按"保留 30% 基元"。
   现论文的 30% 约定把 3.33× 的剪枝与 2.57× 的 8-bit 量化放在同一列，两者码率差 30%。
2. **加一行"免费基线"**：4-bit SH 量化（3.47×，覆盖率损失 ≤0.05 pp）应作为所有剪枝实验的对照。
   任何剪枝准则若在 3.33× 掉 >1 pp，就已经输给这条不挑基元的基线。
3. **N12 的 30% 表要标注口径**：它比较的是"同一保留率下选哪些基元"，在**该保留率**上有效；
   但它不能被读成"这就是该码率下最好的做法"——A4 说明该码率下有免费得多的做法。
4. **方法路线（A 系列）到此可以正式收尾**：五轮尝试（A1 尾部占据、A2 因果有限差分、A3 比特分配、
   A4 联合、以及 N11 的投影掩码）都指向同一件事——**证书泛函没有它能使上劲的动作空间**：
   排序/删除被非局部遮挡证伪，比特分配在本区间退化为零损失。这一条比"某准则不如 Fisher"更有价值。
