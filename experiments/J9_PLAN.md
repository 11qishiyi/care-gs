# J9 — 规律在"不同情境"下的适用性（预注册，2026-11-27 23:5x，数据未采）

## 0 要回答什么

论文现在的规律是：**覆盖率损失由编辑的扰动是否有界决定，而与编辑强度无关**。它是在**一个容差（α=0.1）、一个泛函
（逐像素绝对误差、通道平均）、两个可复现资产 + 四个不可重建孪生**上测出来的。这一轮用同一批编辑、同一 q
把它在四个方向上加压：

| 方向 | 变化 | 若规律成立应看到 |
|---|---|---|
| **容差** | α ∈ {0.01, 0.02, 0.05, 0.1, 0.2, 0.3} | 两族在**每个** α 上都不重叠；差值随 α 变化但不换号 |
| **泛函** | 绝对误差 vs 平方误差 | 分离在所有 α 上保持（平方误差更看重尾部，可能**放大**几何族的劣势） |
| **聚合层级** | 逐视图 vs 池化 | 逐视图看分离是否成立（若只在池化后成立，说明它是平均值效应） |
| **场景** | bicycle + flowers / bonsai / counter（paper 视为内部测量） | 分离在新增场景上同样成立 |

## 1 方法（为什么能一次渲染回答四个问题）

原始残差图约 1 GB/场景-变体，且随节点释放丢失。这一轮改为**存分位数表**：对每个 (scene, variant, view) 存
2000 个分位点上的误差值（绝对值与平方各一张）。于是：

- 任意 α 的覆盖率 = 在干净模型的 q_α 上查表；
- 任意泛函 = 用对应那张表；
- 逐视图 = 不池化直接用该视图的表。

一张表 ≈ 1 MB/场景，可随 artifact 长期保存——这也修掉了"56 格网格不可再分析"的老问题。

## 2 判据（跑之前钉死）

| # | 判据 | 判定 |
|---|---|---|
| C1 | 在 **6 个 α 全部**上，几何族的最小损失 > 属性族的最大损失（不重叠） | 成立 → "容差无关"；否则记录在哪个 α 上破裂 |
| C2 | 平方误差泛函下，几何族的相对劣势 ≥ 绝对误差下的 | 成立 → 尾部解释；不成立则如实报告 |
| C3 | 逐视图分离率 ≥ 80%（至少 8 个检查点里 6 个的**每个**视图都分离） | 成立 → 不是聚合假象 |
| C4 | 新场景（flowers/bonsai/counter 中至少 2 个）上满足 C1 | 成立 → 跨场景；否则限定为"bicycle/stump 上成立" |

**失败处置**：任一判据不成立，摘要与 §5.2 必须加上对应限定，**不得**只说成立的方向。
