# M5 规格：把 RD 曲线搬到实测字节轴上（预注册 2026-11-13 20:15，数据落盘前）

## M5.0 动机

M4 测出：解析模型 `bytes = 11·b_geo/8 + 3K·b_sh/8 + 2` 在四个资产、五种配置上**全部严格上界**（G1 通过、G2 无排序反转），但**保守程度依族而变**：

| 配置 | bicycle | flowers | stump | treehill | 模型/实测 富余 |
|---|---|---|---|---|---|
| `clean` | 236 → 205.73 | 236 → 208.72 | 236 → 213.33 | 236 → 203.19 | 9.6–13.9 % |
| `sh4_g16` | 48 → 38.62 | 48 → 39.43 | 48 → 38.84 | 48 → 38.90 | 17.9–19.6 % |
| `m16_o8_sh3` | 34 → 24.73 | 34 → 25.60 | 34 → 24.94 | 34 → 25.17 | 24.7–27.3 % |
| `m16_o6_sh2` | 26 → 15.14 | 26 → 15.43 | 26 → 15.33 | 26 → 15.37 | 40.7–41.8 % |
| `p30`（剪枝） | 236 → 207.22 | 236 → 211.32 | 236 → 215.02 | 236 → 206.91 | 8.9–12.3 % |

**量化越狠、实测越省**（`m16_o6_sh2` 模型 26 B 实测 15.1–15.4 B，−41 %），而剪枝族几乎不省（它把 SH 留在 fp32）。这意味着：

1. 模型轴**系统性低估了 QFP 的压缩倍率**（把 4.92× 记成实测 6.1×，把 9.08× 记成 15.6×），
2. 也**高估了剪枝的倍率**（3.33× → 实测约 3.16×），
3. 所以 M1–M3 的 **D1/E1 差值是在一个对 QFP 不利的码率轴上算出来的**。

但「不利」只是方向判断。M1–M3 的每一条判定都印在模型轴上，必须**原样再跑一遍实测轴**才能声称结论在真实编码器下成立。M5 就是这件事：不新增任何变体、不改任何判据阈值，只把 `rate` 的来源从名字换成 `m4_bytes` 的实测。

## M5.1 码率定义（实测轴）

对每个 `(资产, 变体)`：

```
rate_measured = N · fp32_bytes_per_prim(deg_scene) / (stored · bpp_measured)
bpp_measured  = zstd(level 12) ∘ morton(重建位置) ∘ 位平面打包(注册位宽) 的 每存储基元字节数
```

`stored` 为剪枝后保留的基元数（`p<kk>` 为 `round(kk·N)`、其余为 `N`），Morton 顺序由**重建位置**计（解码端可复算，无额外边信息），SH 尺度按注册模型统一记 2 B。全部字节按「我们真的会发出去的格式」计量：纯 bit-pack + Morton + zstd，不含熵模型的额外先验。

**与 M4 的口径差异（必须写进论文）**：M4 只测 5 个配置 × 4 资产，M5 测 **21 个变体 × 8 资产**（= M3 的完整网格），因此 M5 的判据是 M3 判据在实测轴上的**逐字重放**，不是新判据。

## M5.2 判据

- **F1（支配性在实测轴上成立）**：`E1` 的阈值原样沿用（共同覆盖的码率点中 ≥4 点、每点 QFP 覆盖损失比 prune 小 ≥3.0 pp、配对区间不含 0、≥6/8 资产同向）。判 **通过/不通过**，不接受任何阈值调整。
- **F2（近无损前沿在实测轴上仍 ≥8×）**：`E3` 原样沿用（单变体 ≤1.0 pp 且 ΔPSNR ≤0.3 dB、码率 ≥8×、≥6/8 资产有成员）。
- **F3（族内次序不变）**：对每个资产、每个族（`prune`/`qfp`），按模型码率排出的成员次序与按实测码率排出的次序必须完全一致（Kendall τ = 1）。若某族内部次序翻转，说明该族的插值曲线会跨错点，F1 的结论只能当「近似」报告——这条是把 M4 的 G2（跨配置无反转）加严到**族内逐对**。

## M5.4 禁止条款

- 不得只报实测轴的有利点、而把模型轴的不利点略去；两轴必须并排出现在结果表里。
- 不得改 `level 12`、不得改 Morton 定义、不得对某些族单独换编解码器。
- 不得把 `covered=false` 的点当实测点比较（插值仍不外推）。
- F1/F2/F3 的阈值不得因实测结果调整（与 M1–M3 相同纪律）。
