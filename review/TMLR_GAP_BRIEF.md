# TMLR 差距调研 · 共享简报（所有 scout 先读这一页）

> 目的：调研 TMLR（Transactions on Machine Learning Research）**最近发布的论文**，
> 与我们手上的 3DGS「质量证书失效」工作做差距分析。
> 本文件只放**共用事实与操作规范**；结论由 Lead 汇总，scout 只负责各自的卡片文件。

## 一、我们的工作（事实基线，不要改写结论，只引用）

- 题目方向：**3DGS 资产的质量证书（保形/覆盖率预测）在几何编辑后失效**——一篇**测量与工具**类论文，不是方法创新。
- 核心结论：剪枝到 30% 使保形覆盖率掉 **10.9–18.6pp**（4 个已收敛场景，16–25 留出视角/场景，400 次随机划分的配对区间全部排除零）；
  SH 阶数 3→1、SH 8-bit 量化**不改变**覆盖率（≤0.7pp）；修复只需 **2–4 个留出视角**，但重标定把区间放宽 **26–71%**。
- 四条证据：① 失效只出现在几何编辑，且随预算非线性（70/50/30/10% → 1.0/4.9/22.1/60.0pp）；
  ② 评测口径（GT 逐图归一化 vs 原口径）把幅度低估最多 **2.4×**；③ 覆盖率与效用不同调（36 格阈值扫描）；
  ④ 四把尺子（coverage / local / registration / pose）在同一编辑下差 **4–11 倍**。
- 证书**低估实际损失 2–12 倍**：覆盖率 −4.6pp 时重定位任务掉 −16.8pp。
- 适用区间：只在**已优化收敛**的模型上成立（训练收敛 ≳2M 基元的发布检查点），与基元数量无关；
  从零短训的轻量模型为 −0.8~+3.2pp（**混淆声明**，论文里的已知弱点）。
- 已否掉的 10 个方向（附录）：单遍方差泼溅、耦合二阶矩、带保证符号层、后处理剪枝两算子、内核加速、
  任务感知预算分配、尾部加权剪枝、按证书剪枝、外推到轻量模型、无标签自检（撤回）。
- 关键方法论教训：分块划分破坏交换性；训练视角混入标定集会掩盖退化；**用标定集自检是循环论证**。
- 主文位置：`PAPER_certificate_invalid_v3.md`、`submission/final/main.tex`、`DOC: SUBMISSION_CHECKLIST.md`、
  `review/LITERATURE_SURVEY_2026-11.md`（arXiv/OpenAlex/S2 四路检索，结论：无同题论文）。

## 三、取摘要的操作规范（重要，照做）

1. **OpenReview API 被 Cloudflare 拦**（`api2.openreview.net` 会返回 "Verifying your browser"）。不要在这上面反复试。
2. 可行路径，按优先级：
   - `web_search`：用**标题加引号**搜，结果里常直接带 arXiv 摘要或项目页；
   - `web_fetch` `https://arxiv.org/abs/<id>`：命中 arXiv 后有完整摘要与编号；
   - `web_fetch` `https://mlanthology.org/tmlr/2026/<slug>/`：该站有 TMLR 单篇页，带 Abstract（slug 形如 `jiang2026tmlr-brightdreamer`，可用搜索找到）；
   - 作者项目页 / 实验室页；
   - `https://jmlr.org/tmlr/papers/bib/<id>.bib` 只有元数据（无摘要），仅用于核实标题作者与月份。
3. **绝不编造**。取不到摘要就在卡片里写 `abstract: 未取到（仅标题/作者）`，并只基于标题做**受限**推断（明确标注是标题推断）。
4. 每篇至少核实：标题、作者、TMLR 月份、是否有 arXiv/代码、**它自己声称的贡献句**（引自摘要原文，可英文原句）。
